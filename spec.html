下書きメモ帳 設計仕様書 検討中(ver未確定)

1. 概要

Windowsのメモ帳と同等の書式なしテキスト編集を、PWA(ブラウザで動くアプリ)として提供する。会社PC(管理者権限なし)とAndroidで、インストールなしでもオフラインで使えることを重視する。

2. 要件

区分内容
対象端末Windows PC(Edge / Chrome)、Android(Chrome)
インストール不要(任意でPWAとしてインストール可)
オフライン初回アクセス後はネット接続なしで起動・編集・保存できる
文書方式1タブ1ファイル(メモ帳と同じ)。複数タブ同時利用可
同期なし(データは端末内のみ。外部送信なし)
公開GitHub Pages(公開リポジトリ)。置くのはアプリ本体のみ
共通仕様エラーログ保存と次回起動時の通知、設定画面から取扱説明書を参照

3. 動作環境・制約

  • ファイルへの直接保存(File System Access API)はChromium系(Edge / Chrome、Chrome Android 132以降)のみ。非対応・会社ポリシーで禁止(DefaultFileSystemWriteGuardSetting 等)の場合はダウンロード保存に自動で切り替える。
  • Service Worker は https または localhost でのみ動作する。file:// で開いた場合はオフライン機能なし。
  • Chrome は Ctrl+N/T/W をページに渡さないため、新しいタブは Alt+N、タブを閉じるは Alt+W、タブ切り替えは Alt+1~9 とする(Ctrl+Tab もブラウザが使うため使わない)。
  • 保存時の文字コードは UTF-8(BOMなし)固定。TextEncoder が UTF-8 のみ対応のため。読込は UTF-8 / UTF-8(BOM) / UTF-16 LE・BE(BOM付き) / Shift_JIS(UTF-8として不正な場合)。
  • 会社ポリシー ClearBrowsingDataOnExit 有効時は、閉じると一時保存・キャッシュが消える。検知は不可能なため、初回起動と同じ扱いで注意を表示する。

5. 構成と処理の流れ

起動時

  1. 空のタブ(文書)を1つ作り、設定(localStorage)を読み込んでテーマ等を反映
  2. 未確認のエラーログがあれば赤バナーで通知
  3. 一時保存(IndexedDB)から復元候補を探し、あれば青バナーで案内。なく、かつ訪問記録もなければ「初回またはデータ消去の可能性」を黄バナーで表示
  4. Service Worker を登録、persist() を要求

タブ(文書)

文書は配列 docs で管理し、表示中の文書を D、その入力欄を ed とする。文書ごとに専用の textarea を持ち、表示中以外は hidden にする(ブラウザ標準の「元に戻す」履歴をタブごとに保つため)。

  • 新しいタブ:textarea とタブ見出しを作り、表示を切り替える。
  • 開く(ファイル・最近使ったファイル・D&D):同じファイル(isSameEntry)を開いているタブがあればそこへ切り替える。なければ、表示中のタブが白紙(無題・未変更・空)ならそれを使い、そうでなければ新しいタブで開く。
  • 閉じる:未保存なら保存確認(保存/保存しない/キャンセル)。最後の1枚を閉じたら白紙のタブを1つ作る。
  • 画面ごと閉じる(beforeunload):未保存のタブが1つでもあれば確認する。

文書ごとの状態

名前内容
id / ta / tabEl文書ID、入力欄(textarea)、タブ見出しの要素
fileName / handle開いているファイル名と、ファイル参照(FileSystemFileHandle。ダウンロード方式では null)
lastModified開いた/保存した時点のファイル更新時刻(競合検知に使用)
dirty未保存の変更があるか
eol / enc改行コード(CRLF/LF)、読み込んだ文字コード
changed / draftSaved前回の一時保存以降に変更があるか、一時保存が存在するか(変更のない文書は書き直さない)

画面全体の状態(state)は zoom(倍率)、pending(保存確認後に続ける処理)、updating(更新中)のみ。

貼り付け

  • document の paste で処理する。入力欄で text/plain がある通常の貼り付けはブラウザに任せる(元に戻すが効く)。
  • フォーカスが入力欄以外(ボタン・メニュー・本文外)にあるときも、表示中のタブに貼り付ける。検索欄・ダイアログ内の入力欄は通常どおり。
  • text/plain が空で text/html があれば、文字だけを取り出す(表はセルをタブ、行を改行で区切る)。
  • 文字が何もなければ、クリップボードの形式名と考えられる原因を黄バナーで表示する。
  • ボタン操作の後は入力欄にフォーカスを戻す(ダイアログ表示中・検索欄などの入力中を除く)。
  • 「編集 → 貼り付け」は navigator.clipboard.readText を使う。許可されない環境では Ctrl+V を案内する。

6. データ保存設計

保存先キー内容
localStoragenp.settings設定(テーマ、折り返し、文字サイズ、自動保存、改行コード、ステータスバー)
localStoragenp.errorlog / np.lastSeenLogエラーログ(最大50件)と、通知済みの最終時刻
localStoragenp.alive.<tabId>タブの生存記録(4秒ごと更新、pagehideで削除、3分で失効、1日で掃除)
localStoragenp.visited訪問済みの印
sessionStoragenp.tabIdタブ識別子(再読み込みでは維持。タブ複製時は新規発行)
IndexedDB notepad-db / draftstabId:文書ID一時保存 {text, name, eol, t}。文書(アプリ内タブ)ごとに1件。入力停止1.5秒後、画面が隠れたとき、閉じるときに書き込み。保存・タブを閉じる・破棄で削除。旧形式のキー(tabId のみ)も復元対象として扱う
IndexedDB notepad-db / recent時刻+乱数最近使ったファイル {handle, name, t}。最大10件、同じファイルは isSameEntry で重複排除

復元候補:今開いている文書の分は除く。自ブラウザタブの分は起動時(再読み込み)の案内が終わるまで、他ブラウザタブの分は生存記録が失効しているもののみ。新しい順に1件ずつ案内し、2件以上なら「すべて復元」も表示する。復元は新しいタブ(白紙のタブがあれば再利用)に行い、新しいキーで一時保存を書いてから元のキーを削除する。IndexedDB が使えない場合はメモリに退避し、警告を表示する。

7. ファイル入出力

  • 開く:showOpenFilePicker → 不可なら input[type=file]。ドラッグ&ドロップは getAsFileSystemHandle が使えればファイル参照ごと取得する。
  • 保存:ファイル参照があれば createWritable で上書き。なければ showSaveFilePicker(初期名はファイル名、無題なら1行目)。SecurityError / NotAllowedError のときはダウンロード保存に切り替えて警告する。
  • 改行:内部は LF。保存時に eol が CRLF なら変換する。
  • 印刷:beforeprint で本文を印刷専用領域に複製し、印刷用CSSで本文のみ出力する。

8. 競合の検知

  • 上書き前の確認:保存直前に getFile().lastModified を取得し、state.lastModified より新しければ確認ダイアログを出す。
  • アプリ内のタブ:同じファイルを開こうとしたら、既存のタブに切り替える(2つ目は開かない)。
  • ブラウザの複数タブ・ウィンドウ:BroadcastChannel「notepad-sync」でファイル参照とファイル名を送り、受信側はアプリ内の全タブと isSameEntry で比較する。opened(開いた)→ 相手が alsoOpen で応答し、双方に警告。saved(保存した)→ 同じファイルを開いている他のブラウザタブに警告。

9. オフライン・更新

  • install でアプリの全ファイル(取扱説明書・本書を含む)をキャッシュ。読み込みはキャッシュ優先。キャッシュにない画面はネットから取得し、オフラインで取得できない場合のみ index.html を返す。
  • 新しい sw.js を検知すると waiting 状態で待機し、画面に「新しいバージョンがあります」を表示。「今すぐ更新」で全タブの一時保存を書き込み → SKIP_WAITING → controllerchange で再読み込み → 自ブラウザタブの書きかけを復元案内(「すべて復元」でまとめて戻せる)。
  • 1時間ごとに更新を確認する。

10. 画面仕様

  • 構成:タブ列(アイコン・タブ・「+」)/メニュー(ファイル・編集・表示)/通知バナー(更新・エラー・復元・注意)/検索バー/本文/ステータスバー
  • アプリ内タブの見出し:「● 」(未保存時)+ ファイル名。無題は「無題: 1行目の冒頭20文字…」。✕で閉じる。多いときは横スクロール。画面幅600px以下では幅を狭くする。
  • ブラウザのタブ見出し:表示中の文書の見出し+「(他 n タブ・未保存 m)」
  • 編集メニュー:元に戻す・やり直し/切り取り・コピー・貼り付け/検索・置換・行へ移動/すべて選択・日付と時刻
  • ステータスバー:行・列、文字数(改行を除く、サロゲートペアは1文字)、保存状態、倍率、改行コード、文字コード。画面幅600px以下では後半3項目を隠す。
  • テーマ:ライト/ダーク/システム。Windows 11メモ帳に近い配色。

11. ショートカット

取扱説明書6章と同じ。新しいタブ Alt+N、タブを閉じる Alt+W、タブ切り替え Alt+1~9、開く Ctrl+O、最近 Ctrl+Shift+O、保存 Ctrl+S、名前を付けて Ctrl+Shift+S、印刷 Ctrl+P、検索 Ctrl+F/F3、置換 Ctrl+H、行移動 Ctrl+G、日時 F5、ズーム Ctrl++/-/0。

12. エラー処理・ログ

  • 各操作は try/catch で囲み、logError(発生箇所, 内容) で記録・トースト表示。window の error / unhandledrejection も記録する。
  • ログは最大50件。次回起動時、前回確認以降のエラー件数と最新内容を赤バナーで通知する。
  • ユーザーのキャンセル(AbortError)はエラーとして扱わない。

13. 公開・更新手順

  1. GitHubの公開リポジトリにファイル一式をルートに置く。
  2. Settings → Pages → Source:Deploy from a branch、Branch:main / (root)。
  3. 更新時:ファイルを差し替え、sw.js の CACHE_VERSION を必ず変更する。

14. 受け入れ条件

  • オンラインで一度開いた後、オフラインで再読み込みしても起動・編集・保存できる
  • 複数タブの書きかけが混ざらず、閉じたタブの書きかけを別タブで復元できる
  • アプリ内でタブを追加・切り替え・閉じることができ、切り替えても内容と「元に戻す」履歴が保たれる。未保存タブを閉じると確認が出る
  • 再読み込み後、複数タブの書きかけを「すべて復元」で戻せる(一時保存が重複しない)
  • ボタンやメニューを押した直後でも Ctrl+V で本文に貼り付けられる。Excelの表はタブ区切りで貼り付く。文字のないクリップボードでは理由が表示される
  • 同じファイルを2タブで開くと双方に警告が出る/外部で変更されたファイルの上書き前に確認が出る
  • 最近使ったファイルから開ける(最大10件、重複なし)
  • sw.js 更新時に更新バナーが表示され、「今すぐ更新」で書きかけを保ったまま新版になる
  • ドラッグ&ドロップで開ける/印刷で本文のみ出力される
  • エラー発生後の次回起動でエラー通知が出る
  • Shift_JIS・UTF-16 ファイルが文字化けせず開ける
