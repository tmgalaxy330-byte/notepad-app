1. このアプリについて

Windowsの「メモ帳」と同じ感覚で使える、文章の下書き用ツールです。ブラウザ(Edge・Chrome)で動き、一度開けばインターネットにつながっていなくても使えます。

  • 書いた文章は、あなたの端末の中だけに保存されます。インターネット上には送信されません。
  • インストールは不要です(インストールしてアプリのように使うこともできます)。
  • パソコンとスマートフォンの間で、文章は共有(同期)されません。

2. 使い始める

2-1. Windows PC(Edge または Chrome)

  1. アプリのURLをEdgeかChromeで開きます(1回目だけインターネット接続が必要です)。
  2. お気に入り(ブックマーク)に登録しておくと、次から簡単に開けます。
  3. (任意)アドレスバー右側の「アプリをインストール」アイコンを押すと、専用のウィンドウで開けるようになります。会社の設定によっては表示されませんが、ブラウザのままでも同じように使えます。

2-2. Android(Chrome)

  1. アプリのURLをChromeで開きます。
  2. 右上の「︙」メニューから「ホーム画面に追加」(または「アプリをインストール」)を選ぶと、ホーム画面から起動できます。

3. 基本の使い方

3-1. 開く・保存

操作方法説明
新しいタブファイル → 新しいタブ(Alt+N)、またはタブの右の「+」新しいタブを開き、白紙から書き始めます。今のタブの内容はそのまま残ります(5章)。
開くファイル → 開く(Ctrl+O)、またはファイルを画面にドラッグ&ドロップ.txt などのテキストファイルを新しいタブで開きます(今のタブが白紙ならそのタブを使います)。すでに開いているファイルなら、そのタブに切り替わります。Shift_JIS や UTF-16 のファイルも読み込めます。
上書き保存ファイル → 上書き保存(Ctrl+S)開いているファイルにそのまま保存します。初めての保存では保存先を選びます。
名前を付けて保存Ctrl+Shift+S別の名前・場所に保存します。
すべて保存ファイル → すべて保存(Ctrl+Alt+S)未保存のタブを順番に保存します。無題のタブは保存先を聞かれます。保存先の選択をキャンセルすると、そこで止まります。
保存のしかたは環境によって変わります。
・通常:開いたファイルに直接上書き保存されます(初回は「編集を許可しますか」と確認されます)。
・会社の設定でファイルへの直接保存が禁止されている場合:自動的に「ダウンロードフォルダへの保存」に切り替わります。
今どちらの方式かは「設定 → この環境の状態」で確認できます。

文字コード(Shift_JIS で保存したいとき)

  • 開いたファイルは、元の文字コードのまま保存します(Shift_JIS のファイルは Shift_JIS のまま)。
  • 文字コードを変えるには、画面右下の文字コード表示(「UTF-8」など)をクリックするか、ファイル → 文字コードを変更… を選びます。選べるのは UTF-8 / UTF-8 (BOM付き) / Shift_JIS / UTF-16 LE / UTF-16 BE です。
  • 新しく作るファイルの文字コードは「設定 → 保存時の文字コード」で決められます(初期値は UTF-8)。
  • Shift_JIS では表せない文字(絵文字、「𠮷」などの一部の漢字)があると、保存の前に知らせます。「?」に置き換えて保存するか、キャンセルして UTF-8 に変えてください。
  • Mac などで入力された「〜」「−」「—」などは、Windows で同じに見える文字に置き換えて Shift_JIS で保存します。

開いた後に、別のタブや別のアプリで同じファイルが書き換えられていた場合は、上書き保存の前に「上書きしますか?」と確認します。

3-2. 最近使ったファイル

ファイル → 最近使ったファイル(Ctrl+Shift+O)で、最近開いた・保存したファイルを最大10件表示します。選ぶと、ファイルを探し直さずに開けます。

  • 開くときに「ファイルの閲覧を許可しますか」と聞かれることがあります。「許可」を押してください。
  • ファイルを移動・削除していた場合は開けず、一覧から自動的に外れます。
  • ファイルへの直接保存ができない環境では、このメニューは表示されません。

3-3. 編集・検索

  • 元に戻す Ctrl+Z / やり直し Ctrl+Y
  • 検索 Ctrl+F:検索バーに文字を入れて Enter(次へ)・Shift+Enter(前へ)。見つかった件数も表示されます。
  • 置換 Ctrl+H:「置換」で1件ずつ、「すべて置換」でまとめて置き換えます。すべて置換も Ctrl+Z で元に戻せます。
  • 行へ移動 Ctrl+G、日付と時刻を挿入 F5
  • 文字を選ぶと、ステータスバーに「選択 120 / 3,400 文字」のように選んだ部分の文字数が出ます(改行は数えません)。文字数制限のある文章に便利です。

正規表現での検索・置換

検索バーの「正規表現」にチェックを入れると、パターンで探せます。例:

検索置換結果
\s+$(空)行末の余分な空白を消す
^・すべての行の頭に「・」を付ける
(\d+)円¥$1「100円」→「¥100」($1 はかっこの中身)
\n{3,}\n\n ※3行以上続く空行を1行にする

※置換欄の \n は改行になりません。改行を入れたいときは、置換欄に改行をコピーして貼り付けてください。正しくないパターンのときは「正規表現が正しくありません」と表示されます。

定型文

編集 → 定型文…(Alt+T)で、登録した文章をカーソルの位置に挿入できます。あいさつ文や議事録のひな形など、よく使う文章を登録しておくと便利です。

  • 下の欄に名前と本文を入れて「追加」。✎ で編集、✕ で削除できます。
  • 本文に {日付} {時刻} と書くと、挿入したときの日付・時刻に置き換わります。
  • 最初から「あいさつ(社内)」「議事録のひな形」が入っています(不要なら削除してください)。
F5 はこのアプリでは「日付と時刻の挿入」です。ページの再読み込みにはなりません。

3-4. 表示・印刷

  • 拡大・縮小:Ctrl++ / Ctrl+-(Ctrl+マウスホイールでも可)、元に戻す Ctrl+0
  • 右端で折り返す・行番号・ステータスバーの表示:「表示」メニュー。行番号は1行を1段で表示するときだけ正しく並ぶため、行番号を表示すると「右端で折り返す」はオフになります。
  • ダークモード:右上の 🌙 / ☀ ボタン
  • 印刷:ファイル → 印刷(Ctrl+P)。本文だけが印刷されます。

画面下のステータスバーには、カーソルの位置(行・列)、文字数(改行を除く)、保存状態、倍率、改行コード、文字コードが表示されます。

画面上部のタブと、ブラウザのタブ見出しには、ファイル名(無題の場合は1行目の冒頭)が表示されます。先頭の「●」は、まだ保存していない変更があるという意味です。

4. 一時保存と復元

書いている内容は、数秒ごとにブラウザの中へ自動で一時保存されます(タブごとに別々に保存されます)。

4-1. 前回のタブを再開

Windows 11 のメモ帳と同じように、アプリを閉じたときに開いていたタブ(保存済みのファイルを含む)が、次に開いたとき自動で元に戻ります。タブの順番と、表示していたタブも戻ります。

  • 保存済みのファイルのタブは、ブラウザを起動し直した後だと「ここをクリックしてください」と表示されることがあります。本文をクリックし、ファイルを読む許可を求められたら「許可」を押すと読み込みます。読み込む前のタブは保存できません(空の内容で上書きしてしまうのを防ぐため)。
  • アプリを2つ目のウィンドウ(ブラウザのタブ)で開いたときは、白紙から始まります。
  • この機能は「設定 → 前回のタブを再開する」でオフにできます。オフのときは、書きかけを「復元する」で案内します。

4-2. 書きかけの復元と一覧

自動で戻らなかった書きかけ(別のウィンドウで書いていたものなど)は、次に開いたとき「書きかけの内容があります」と表示されます。「復元する」で1件、「すべて復元」でまとめてタブとして戻せます。ファイル → 書きかけ一覧… では、すべての書きかけを見て、選んで復元・削除できます。

一時保存はあくまで保険です。大切な文章は必ず「保存」でファイルにしてください。
会社のPCなどで「ブラウザを閉じると閲覧データを消す」設定になっていると、一時保存も消えます。この場合、起動時に注意のメッセージが表示されます。
Edgeでは、アドレスバーに edge://policy と入力すると会社の設定を確認できます。「ClearBrowsingDataOnExit」が「true」なら、閉じると消える設定です。

「書きかけの復元」で戻した内容は、元のファイルとのつながりが外れています。「名前を付けて保存」で保存し直してください(「前回のタブを再開」で戻ったタブは、元のファイルとつながったままです)。

5. タブで複数の文章を扱う

Windows 11 のメモ帳と同じように、1つの画面の中でタブを切り替えて、いくつもの文章を同時に書けます。ほかの文章を閉じる必要はありません。

操作方法
新しいタブタブの右の「+」、または Alt+N
タブの切り替えタブをクリック、または Alt+1~8(左から何番目か)、Alt+9(いちばん右)
タブを閉じるタブの「✕」、ホイールクリック、または Alt+W。未保存の変更があれば保存するか確認します。
タブの並べ替えタブをドラッグして、好きな位置に移します
まとめて操作タブを右クリック → 保存/名前を付けて保存/閉じる/他のタブを閉じる/右側のタブを閉じる/変更のないタブを閉じる/すべて保存
  • 「元に戻す」(Ctrl+Z)の履歴はタブごとに分かれています。タブを切り替えても消えません。
  • タブがたくさんあるときは、タブの列を横にスクロールできます。
  • ブラウザやアプリの画面ごと閉じるときに未保存のタブが1つでもあれば、ブラウザが「このサイトを離れますか?」と確認します。

ブラウザのタブ・ウィンドウを複数開いた場合

  • アプリ自体をブラウザの別タブや別ウィンドウで開いても使えます。一時保存はそれぞれ分かれていて、混ざりません。
  • 同じファイルを2か所(アプリ内の別タブを含む)で開こうとすると、アプリ内ならそのタブに切り替わり、別のブラウザタブ・ウィンドウなら「別のブラウザタブ(またはウィンドウ)でも開かれています」と警告が出ます。後から保存した方の内容で上書きされるので注意してください。
  • 閉じたブラウザタブの書きかけは、次にアプリを開いたときに「復元する」で案内します(複数あるときは新しいものから順番に案内します。「書きかけ一覧」でまとめて見ることもできます)。

8. アプリの更新

新しい版が公開されると、画面上部に緑色で「新しいバージョンがあります」と表示されます。「今すぐ更新」を押すと、書きかけの内容を保ったまま新しい版に切り替わります。「あとで」を押した場合は、次に開いたときにまた案内されます。

更新の確認にはインターネット接続が必要です。オフラインのときは、今の版のまま使えます。

9. 困ったとき

症状対処
保存するとダウンロードフォルダに入ってしまう会社の設定でファイルへの直接保存が禁止されているか、古いブラウザの可能性があります。ダウンロードされたファイルを目的のフォルダに移してください。
オフラインで開けない一度もインターネット接続中に開いていないか、ブラウザのデータが消去された可能性があります。ネットにつながった状態で一度開いてください。
書きかけが復元されないブラウザを閉じるとデータが消える設定の可能性があります(4章)。こまめにファイルへ保存してください。
文字化けするUTF-8・UTF-16・Shift_JIS 以外の文字コード(EUC-JPなど)には対応していません。
「テキストファイルではないため開けません」と出るExcel(.xlsx)・Word(.docx)・画像などは開けません。Excelの内容を使うときは、セルをコピーして貼り付けてください。
大きなファイルで入力が重い数MBを超えるファイルでは、ブラウザの入力欄そのものが重くなります(5MBを超えるファイルは開く前に確認します)。ログなどの大きなファイルは、必要な部分だけをコピーして使ってください。
タブに「ここをクリックしてください」と出る前回のタブを再開したとき、ファイルを読む許可がまだない状態です。本文をクリックし、「許可」を押してください(4-1)。
保存するとき「保存できない文字があります」と出るShift_JIS では表せない文字があります。UTF-8 で保存するか、「?」に置き換えて保存してください(3-1)。
行番号を出すと折り返しが消えた行番号は1行1段のときだけ正しく並ぶため、自動で折り返しをオフにしています。折り返しをオンにすると行番号は消えます。
Ctrl+Nで新しいウィンドウが開くアプリ内の新しいタブは Alt+N です。
Excelなどからコピーした文字が貼り付けられない ① 編集 → 貼り付けの診断 を開き、枠をクリックして Ctrl+V を押します。結果で原因を切り分けられます。
・「内容が届きませんでした」:会社のセキュリティ機能(情報漏えい対策:DLP。例:Microsoft Purview の「ブラウザーへの貼り付け」制限)やブラウザの拡張機能が、このサイトへの貼り付けを止めている可能性が高いです。Windowsのメモ帳には貼れてもブラウザには貼れない、という症状になります。社内の担当部署に、このアプリのアドレスへの貼り付けを許可できるか確認してください(アプリ側では解除できません)。
・「文字が届いていません」:Excelのコピーが解除されています(点線の枠が出ている状態でもう一度コピー)。図やグラフ(画像)は貼り付けできません。
・「文字は届いています」なのに本文に入らない:アプリの不具合の可能性があります。「結果をコピー」で結果を開発者に伝えてください。
② 同じ内容を、同じブラウザの他のサイト(検索欄など)に貼れるかも試してください。他のサイトにも貼れなければ、ブラウザや会社の設定が原因です。
「最近使ったファイル」から開けないファイルが移動・削除されたか、アクセスの許可がされていません。「開く」から選び直してください。

10. エラーログ

アプリの使用中にエラーが起きると、その場で通知するとともに記録します(最大50件)。次にアプリを開いたとき、前回のエラーがあれば画面上部に赤いメッセージで知らせます。「ログを見る」または「設定 → エラーログ」で内容を確認できます。不具合を報告するときは、この内容を伝えてください。
