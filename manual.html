1. このアプリについて

Windowsの「メモ帳」と同じ感覚で使える、文章の下書き用ツールです。ブラウザ(Edge・Chrome)で動き、一度開けばインターネットにつながっていなくても使えます。

  • 書いた文章は、あなたの端末の中だけに保存されます。インターネット上には送信されません。
  • インストールは不要です(インストールしてアプリのように使うこともできます)。
  • パソコンとスマートフォンの間で、文章は共有(同期)されません。

2. 使い始める

2-1. Windows PC(Edge または Chrome)

  1. アプリのURLをEdgeかChromeで開きます(1回目だけインターネット接続が必要です)。
  2. お気に入り(ブックマーク)に登録しておくと、次から簡単に開けます。
  3. (任意)アドレスバー右側の「アプリをインストール」アイコンを押すと、専用のウィンドウで開けるようになります。会社の設定によっては表示されませんが、ブラウザのままでも同じように使えます。

2-2. Android(Chrome)

  1. アプリのURLをChromeで開きます。
  2. 右上の「︙」メニューから「ホーム画面に追加」(または「アプリをインストール」)を選ぶと、ホーム画面から起動できます。

3. 基本の使い方

3-1. 開く・保存

開くファイル → 開く(Ctrl+O)、またはファイルを画面にドラッグ&ドロップ.txt などのテキストファイルを開きます。Shift_JIS や UTF-16 のファイルも読み込めます。
上書き保存ファイル → 上書き保存(Ctrl+S)開いているファイルにそのまま保存します。初めての保存では保存先を選びます。
名前を付けて保存Ctrl+Shift+S別の名前・場所に保存します。
保存のしかたは環境によって変わります。
・通常:開いたファイルに直接上書き保存されます(初回は「編集を許可しますか」と確認されます)。
・会社の設定でファイルへの直接保存が禁止されている場合:自動的に「ダウンロードフォルダへの保存」に切り替わります。
今どちらの方式かは「設定 → この環境の状態」で確認できます。
保存すると文字コードは常に UTF-8 になります。Shift_JIS のまま保存することはできません。

開いた後に、別のタブや別のアプリで同じファイルが書き換えられていた場合は、上書き保存の前に「上書きしますか?」と確認します。

3-2. 最近使ったファイル

ファイル → 最近使ったファイル(Ctrl+Shift+O)で、最近開いた・保存したファイルを最大10件表示します。選ぶと、ファイルを探し直さずに開けます。

  • 開くときに「ファイルの閲覧を許可しますか」と聞かれることがあります。「許可」を押してください。
  • ファイルを移動・削除していた場合は開けず、一覧から自動的に外れます。
  • ファイルへの直接保存ができない環境では、このメニューは表示されません。

3-3. 編集・検索

  • 元に戻す Ctrl+Z / やり直し Ctrl+Y
  • 検索 Ctrl+F:検索バーに文字を入れて Enter(次へ)・Shift+Enter(前へ)。見つかった件数も表示されます。
  • 置換 Ctrl+H:「置換」で1件ずつ、「すべて置換」でまとめて置き換えます。すべて置換も Ctrl+Z で元に戻せます。
  • 行へ移動 Ctrl+G、日付と時刻を挿入 F5
F5 はこのアプリでは「日付と時刻の挿入」です。ページの再読み込みにはなりません。

3-4. 表示・印刷

  • 拡大・縮小:Ctrl++ / Ctrl+-(Ctrl+マウスホイールでも可)、元に戻す Ctrl+0
  • 右端で折り返す・ステータスバーの表示:「表示」メニュー
  • ダークモード:右上の 🌙 / ☀ ボタン
  • 印刷:ファイル → 印刷(Ctrl+P)。本文だけが印刷されます。

画面下のステータスバーには、カーソルの位置(行・列)、文字数(改行を除く)、保存状態、倍率、改行コード、文字コードが表示されます。

ブラウザのタブ見出しには、ファイル名(無題の場合は1行目の冒頭)が表示されます。先頭の「●」は、まだ保存していない変更があるという意味です。

4. 一時保存と復元

書いている内容は、数秒ごとにブラウザの中へ自動で一時保存されます。ブラウザが突然閉じても、次に開いたとき「書きかけの内容があります」と表示され、「復元する」で続きから書けます。

一時保存はあくまで保険です。大切な文章は必ず「保存」でファイルにしてください。
会社のPCなどで「ブラウザを閉じると閲覧データを消す」設定になっていると、一時保存も消えます。この場合、起動時に注意のメッセージが表示されます。
Edgeでは、アドレスバーに edge://policy と入力すると会社の設定を確認できます。「ClearBrowsingDataOnExit」が「true」なら、閉じると消える設定です。

復元した内容は、元のファイルとのつながりが外れています。「名前を付けて保存」で保存し直してください。

5. 複数タブで使うとき

  • アプリを複数のタブで開いて、別々の文章を書けます。一時保存もタブごとに分かれています。
  • タブ見出しにはファイル名(無題なら1行目の冒頭)が出るので、どのタブがどの文章か見分けられます。
  • 同じファイルを2つのタブで開くと「別のタブでも開かれています」と警告が出ます。後から保存した方の内容で上書きされるので注意してください。
  • タブを閉じた後の書きかけは、次にアプリを開いたタブで「復元する」を案内します(複数あるときは新しいものから順番に案内します)。

8. アプリの更新

新しい版が公開されると、画面上部に緑色で「新しいバージョンがあります」と表示されます。「今すぐ更新」を押すと、書きかけの内容を保ったまま新しい版に切り替わります。「あとで」を押した場合は、次に開いたときにまた案内されます。

更新の確認にはインターネット接続が必要です。オフラインのときは、今の版のまま使えます。

9. 困ったとき

症状対処
保存するとダウンロードフォルダに入ってしまう会社の設定でファイルへの直接保存が禁止されているか、古いブラウザの可能性があります。ダウンロードされたファイルを目的のフォルダに移してください。
オフラインで開けない一度もインターネット接続中に開いていないか、ブラウザのデータが消去された可能性があります。ネットにつながった状態で一度開いてください。
書きかけが復元されないブラウザを閉じるとデータが消える設定の可能性があります(4章)。こまめにファイルへ保存してください。
文字化けするUTF-8・UTF-16・Shift_JIS 以外の文字コード(EUC-JPなど)には対応していません。
Ctrl+Nで新しいウィンドウが開く新規作成は Alt+N です。
「最近使ったファイル」から開けないファイルが移動・削除されたか、アクセスの許可がされていません。「開く」から選び直してください。

10. エラーログ

アプリの使用中にエラーが起きると、その場で通知するとともに記録します(最大50件)。次にアプリを開いたとき、前回のエラーがあれば画面上部に赤いメッセージで知らせます。「ログを見る」または「設定 → エラーログ」で内容を確認できます。不具合を報告するときは、この内容を伝えてください。
